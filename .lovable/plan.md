

# لوحة تحكم بوت تيليجرام لإدارة المجموعات

## نظرة عامة
لوحة تحكم ويب احترافية باللغة العربية (RTL) للتحكم بجميع وظائف بوت تيليجرام، مبنية على React + Supabase Edge Functions + Telegram Bot API.

## المكونات الرئيسية

### 1. لوحة التحكم الرئيسية (Dashboard)
- إحصائيات عامة: عدد المجموعات، الأعضاء النشطين، التحذيرات، الرسائل
- آخر العمليات الإدارية (سجل الأحداث)
- حالة البوت (متصل/غير متصل)

### 2. إدارة المجموعات
- قائمة المجموعات المتصلة
- إعدادات كل مجموعة: رسالة الترحيب، قفل/فتح الوسائط والروابط
- تشغيل/إيقاف ميزات الترفيه لكل مجموعة

### 3. إدارة الأعضاء
- جدول الأعضاء مع النقاط والمستويات والتحذيرات
- أزرار إجراءات سريعة: حظر، طرد، كتم، تحذير

### 4. سجل العمليات (Logs)
- تسجيل كل العمليات الإدارية مع التاريخ والوقت
- فلترة حسب النوع (حظر، تحذير، كتم، إلخ)

### 5. الهمسات
- عرض سجل الهمسات المرسلة

### 6. إعدادات الترفيه
- تشغيل/إيقاف: Quiz، نكت، حقيقة أم تحدي، الهكر الوهمي
- إدارة الأسئلة والنكت

## البنية التحتية (Supabase)

### جداول قاعدة البيانات
- `telegram_groups` - إعدادات المجموعات
- `telegram_users` - بيانات الأعضاء (نقاط، مستويات، تحذيرات)
- `telegram_whispers` - الهمسات
- `telegram_admin_logs` - سجل العمليات
- `telegram_bot_state` - حالة الاستطلاع (polling offset)
- `telegram_messages` - الرسائل الواردة

### Edge Functions
- `telegram-poll` - استطلاع الرسائل من Telegram (مع pg_cron)
- `telegram-admin` - تنفيذ أوامر الإدارة (ban, kick, mute, warn)
- `telegram-send` - إرسال رسائل ورسائل الترحيب
- `telegram-webhook-handler` - معالجة الأوامر الواردة وتنفيذها

## التصميم
- واجهة عربية RTL بتصميم نظيف وداكن
- ألوان: أزرق تيليجرام كلون أساسي
- متجاوبة مع الموبايل
- أيقونات واضحة لكل قسم
